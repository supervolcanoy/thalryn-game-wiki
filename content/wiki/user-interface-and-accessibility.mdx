## UI Philosophy

The interface should stay readable while preserving immersion:

- reduced persistent clutter,
- context-sensitive prompts,
- and informational emphasis during danger states.

## Core HUD Elements

- Health and stamina indicators
- Hunger/thirst state icons
- Quick-access hotbar
- Interaction prompt
- Conditional Siren counter feedback

## Menu Surfaces

- Inventory
- Crafting UI
- Pause/settings
- Death summary with run metrics

## Accessibility Direction

- Colorblind support
- Subtitle and audio cue assistance
- HUD scale/opacity controls
- Remappable controls and input toggles
